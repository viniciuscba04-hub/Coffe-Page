# Coffe Page

Página web de uma cafeteria desenvolvida com **HTML5 e CSS3** durante meus estudos de desenvolvimento web.

O projeto foi criado com o objetivo de praticar a construção de páginas web, estruturação de conteúdo, estilização com CSS, organização de seções e criação de uma interface visual para um negócio fictício.

---

## Sobre o projeto

O Coffe Page é uma página institucional para uma cafeteria, criada para apresentar o estabelecimento, seus produtos e informações para os clientes.

A página foi desenvolvida utilizando imagens, tipografia personalizada, seções de conteúdo e elementos de navegação.

Este projeto representa uma das primeiras etapas da minha evolução no desenvolvimento **Front-End**, com foco na construção de páginas utilizando HTML e CSS.

## Estrutura da página

A página possui diferentes seções:

### Home

Apresenta a cafeteria e uma chamada principal para o visitante.

Apresenta informações sobre a cafeteria e sua proposta.

### Menu

Exibe diferentes opções de cafés, seus preços e botões de compra.

Apresenta avaliações fictícias de clientes acompanhadas de imagens.

### Endereço

Apresenta a localização da cafeteria utilizando um mapa incorporado do Google Maps.

Possui elementos visuais relacionados aos canais de contato e redes sociais.

## Limitações atuais

O projeto foi desenvolvido como parte dos meus estudos iniciais em desenvolvimento Front-End e possui algumas limitações.

Entre elas:

- Não possui JavaScript implementado.
- Os botões de compra ainda não possuem funcionalidades reais.
- O carrinho de compras é apenas visual.
- Os ícones de pesquisa e redes sociais são elementos visuais.
- Não existe integração com banco de dados.
- Não existe sistema de autenticação.
- Não existe backend.
- Os produtos são apresentados de forma estática.
- Os preços e informações são definidos diretamente no HTML.
- A responsividade pode ser aprimorada.

Essas limitações fazem parte do estágio atual do projeto.
